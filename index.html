Ten characters, the way a ZX Spectrum tape header stores a program name. Spaces are the dots. folio-48 is the machine. The test program is FOLIO.

Collect the yellow leaves. Avoid the red hunter.

FOLIO, DRIFT and PIPS are original programs written for this machine. Castaway is a 2016 game by Juan J. Martínez. Its tape name is castawy, the filename he published, then three spaces. Load a .z80, .sna, .tap, .tzx, .scr or .rom from this computer, or drop it on the screen. Nothing is uploaded.

Q up, A down, O left, P right. Space starts again.

The 48K Sinclair ROM is included. Amstrad have kindly given their permission for the redistribution of their copyrighted material but retain that copyright, and the notice inside the ROM is unchanged. A tape with CLEAR and RANDOMIZE USR starts at that address after the ROM has set the machine up. A loader that only reads the ear is skipped, and the largest CODE block starts instead. When a program later calls that ROM loader, the next matching block in the file is copied into RAM. A snapshot runs with this ROM. FOLIO, DRIFT and PIPS do not use it. A BASIC program with no machine-code entry is refused. A .scr file is the picture only. A 128K .z80 shows the 48K that was paged in.

The PDF runs in desktop Adobe Acrobat, or the free Acrobat Reader 7.0 or later, including current builds through 2026. Allow JavaScript, then Space starts the game. Download Acrobat Reader. The web and mobile Acrobat apps do not run this script.

The game is document JavaScript: a timer repaints the screen. PDFium, the viewer in Chrome, Edge, and other Chromium browsers, is built without that JavaScript engine, so it draws the picture and Space does nothing. macOS Preview and Safari do the same. Firefox runs only a small safe piece of Acrobat JavaScript, not this timer.
